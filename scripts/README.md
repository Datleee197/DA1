# Simulation and GTKWave Helper Scripts

This directory contains a set of helper scripts designed to simplify the process of running simulations and viewing waveforms for the FFT-256 R2²SDF project.

There are **10 scripts** in total: 5 for Linux/Git Bash (`.sh`) and 5 for Windows PowerShell (`.ps1`). They perform exactly the same functions.

## 1. Running Simulations

The simulation scripts automatically handle the following:
1. Running the Python golden model to generate test vectors.
2. Compiling the RTL and Testbench using `iverilog`.
3. Running the simulation using `vvp`.
4. Moving the generated `.vcd` waveform files neatly into the `sim/build/` folder to keep your root directory clean.

### FFT-256 Simulation
Runs the full 256-point architecture simulation, including back-to-back streaming and random stress tests.
- **Linux / Git Bash:** `bash scripts/run_fft256_sim.sh`
- **PowerShell:** `powershell -ExecutionPolicy Bypass -File scripts\run_fft256_sim.ps1`

### FFT-16 Simulation (Sandbox)
Runs the scaled-down 16-point version of the architecture, useful for quick debugging of the control logic.
- **Linux / Git Bash:** `bash scripts/run_fft16_sim.sh`
- **PowerShell:** `powershell -ExecutionPolicy Bypass -File scripts\run_fft16_sim.ps1`

### Run All Tests
Runs the module-level tests, followed by the FFT-16 sandbox, and finally the full FFT-256 regression.
- **Linux / Git Bash:** `bash scripts/run_all_tests.sh`
- **PowerShell:** `powershell -ExecutionPolicy Bypass -File scripts\run_all_tests.ps1`

## 2. Opening GTKWave

The GTKWave scripts make it easy to view the `.vcd` files generated by the simulation scripts.

**Important:** You must run the corresponding simulation script (e.g., `run_fft256_sim.sh`) before opening GTKWave, as the viewer requires the `.vcd` file to exist in `sim/build/`.

### FFT-256 Waveform
- **Linux / Git Bash:** `bash scripts/open_fft256_gtkwave.sh`
- **PowerShell:** `powershell -ExecutionPolicy Bypass -File scripts\open_fft256_gtkwave.ps1`

### FFT-16 Waveform
- **Linux / Git Bash:** `bash scripts/open_fft16_gtkwave.sh`
- **PowerShell:** `powershell -ExecutionPolicy Bypass -File scripts\open_fft16_gtkwave.ps1`

---

## 3. Saving Your GTKWave Layout

By default, GTKWave opens with a blank viewer. You can save your preferred signal arrangement (e.g., clocks, data inputs, and control flags) so you don't have to set it up manually every time.

1. Run the GTKWave script to open the viewer.
2. Add your desired signals to the screen.
3. In GTKWave, click **File > Write Save File**.
4. Save the file as **`scripts/debug_fft256.gtkw`** (or `scripts/debug_fft16.gtkw` for the FFT-16 version).

The next time you run the `open_fft256_gtkwave` script, it will automatically detect your `.gtkw` file and launch GTKWave with all your signals already arranged!
